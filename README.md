# Учебная конфигурация "Управление торговлей и кадрами" (1С:Предприятие 8.3)

Данный проект разработан как демонстрация навыков программирования на платформе 1С:Предприятие 8.3 (уровень Junior). 
Конфигурация реализует сквозной учет торговли, кадров и взаиморасчетов с поставщиками.

## 🚀 Реализованный функционал

### 1. Подсистема "Склад и запасы"
*   **Справочники:** Номенклатура (с артикулами и видами), Контрагенты (с ИНН и видами), Склады.
*   **Документы:** 
    *   `Приходная накладная` (движения по регистрам остатков и взаиморасчетов, запись цен).
    *   `Продажа товаров` (списание остатков с контролем нехватки товара).
    *   `Оплата поставщику` (погашение долга с контролем переплаты).
*   **Регистры:** 
    *   `ОстаткиТоваров` (Регистр накопления).
    *   `ВзаиморасчетыСПоставщиками` (Регистр накопления).
    *   `ЦеныНоменклатуры` (Периодический регистр сведений).

### 2. Подсистема "Кадровый учет"
*   **Справочники:** Сотрудники, Должности, Подразделения.
*   **Документы:** Приём на работу, Кадровый перевод, Увольнение.
*   **Регистры:** `КадроваяИстория` (Регистр сведений, подчиненный регистратору).

### 3. Подсистема "Аналитика и отчеты" (СКД)
*   `Остатки товаров` (Виртуальная таблица остатков, отсечение нулевых остатков).
*   `Движение товаров` (Пакетный запрос с ОБЪЕДИНИТЬ ВСЕ, подтягивание актуальных цен).
*   `Анализ взаиморасчетов` (Вывод сальдо с учетом знака, детализация до документа).
*   `Актуальные кадры` (Срез последних, отбор уволенных).

## 🛠️ Технические фишки (Что показано в коде)

*   **Контроль остатков при проведении:** Использование временных таблиц и левого соединения для выявления нехватки товара до записи движений.
*   **Управляемые блокировки:** Использование `БлокироватьДляИзменения` для предотвращения коллизий при одновременной продаже/оплате.
*   **Оптимизация записи:** Запись цен в регистр сведений осуществляется пакетно (массив наборов записей) после цикла, а не построчно.
*   **Контроль переплаты:** Проверка суммы оплаты на соответствие текущему долгу через виртуальную таблицу остатков.
*   **Работа с СКД:** Группировки, "Детальные записи", вычисляемые поля (ВЫБОР для минуса), условное оформление.

## ⚙️ Как развернуть проект

1. Скачайте файл выгрузки `*.dt` из этого репозитория.
2. Создайте пустую информационную базу в 1С:Предприятие.
3. В Конфигураторе выберите `Администрирование -> Загрузить информационную базу` и укажите скачанный файл `.dt`.
4. Запустите 1С:Предприятие в режиме "Такси".
